# 맥컬러 활용 분석


## 1. 폴더 구조

| 폴더 | 내용 |
|---|---|
| `PBP_Crawling/` | PBP 수집 및 전처리 |
| `GNN/` | GNN용 데이터 생성 및 분석 |
| `Network/` | 네트워크 분석 |
| `Cluster/` | 클러스터 분석 |


## 2. 전체 흐름

1. **데이터 수집** (`PBP_Crawling/`)
   TPBL 공식 사이트에서 레오파즈 42경기 Play-by-Play 수집.
2. **모델링**
   - GNN: 선수 역할 임베딩, 조합별 성과 분석
   - Network: 공출전·어시스트 네트워크 분석
   - Cluster: 선수 역할 유형 군집
3. **인사이트 도출**
   분석 결과 종합 → 맥컬러 활용 방안 정리
